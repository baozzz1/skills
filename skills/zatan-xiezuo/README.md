# 杂谈写作三步法（zatan-xiezuo）

> An Agent Skill that coaches opinion-essay writing (杂谈) in Chinese, adapted from a method shared by Bilibili creator 演播室外有一堆屎蛋.

## 用途

陪作者写杂谈、随笔、观点文：从找观点、验观点，到选文体、搭骨架，再到发出去之后复盘。也能按同一套方法审稿。

分工：观点、情绪、亲身经历都来自作者，agent 不代想、不代编；agent 负责查证事实并附出处，同时按步骤推进。

## 引用源

方法出自 B 站 UP 主 **演播室外有一堆屎蛋** 分享的杂谈写作三步法：<https://space.bilibili.com/399454895/dynamic>

起点观点 / 终点观点、第三人称校验、两栏勘误表、「发动机」与 2×2 文体表、三层逻辑大纲、出产后回到下一篇下笔前的闭环，这些方法本身都归原作者。本 skill 只做了两件事：把原方法整理成 agent 能照着执行的步骤，并补了 agent 的分工和审稿流程。

## 复盘记录

文章发出后，作者说的「不好的地方」会记在 `~/.zatan-xiezuo/retro.md`（本机，不进仓库）。下一篇动笔前，agent 会先读这份记录。
