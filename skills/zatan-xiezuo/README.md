# 杂谈写作三步法（zatan-xiezuo）

> An Agent Skill that coaches opinion-essay writing (杂谈) in Chinese, adapted from a method shared by Bilibili creator 演播室外有一堆屎蛋.

## 用途

陪作者写杂谈、随笔、观点文：从找观点、验观点，到选文体、搭骨架，再到发出去之后复盘。也能按同一套方法审稿。

分工：观点、情绪、亲身经历都来自作者，agent 不代想、不代编；agent 负责查证事实并附出处，同时按步骤推进。

## 引用源

原稿：B 站 UP 主 **演播室外有一堆屎蛋** 的《杂谈写作三步法（v2）》，<https://space.bilibili.com/399454895/dynamic>

以下内容都出自原稿：起点观点 / 终点观点、自我观点察觉、第三人称校验（含金刚狼的例子）、两栏勘误表、观点位置考察、「发动机」与 2×2 文体表、三层逻辑大纲及硬规矩、出产后回到下一篇下笔前的闭环。

## 本 skill 的补充与解读

下面这些不在原稿里，是本 skill 为了让 agent 能照着执行而加的，不代表原作者的意见：

- **分工**：观点、情绪、亲身经历归作者；事实查证归 agent，结论附出处；用户明确拒绝来回确认时，才由 agent 推断论点、一次交付。
- **从哪一步进**：按作者手里已有什么（题目、论点、成稿、已发出）决定从哪步开始。
- **骨架的呈现格式**：按段编号，每段写「这段回答的问题 / 情绪位置 / 放哪些素材和包袱」。
- **审稿流程**：原稿只有一句「审别人稿时先认他的发动机，留强项、换弱项，别把所有作者压成自己」，五步审稿流程由本 skill 展开。
- **复盘记录的存放**：原稿说把不好的地方「归档回下一篇的下笔前」；存放位置 `~/.zatan-xiezuo/retro.md`（本机，不进仓库）和记录格式由本 skill 定。
- **常见翻车表**。
- **「桥段」的含义**：原稿没有定义，本 skill 按剧情复述理解。
